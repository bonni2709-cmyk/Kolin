# KolinAI — локальная нейросеть для генерации картинок (Windows 11, AMD без NVIDIA)

Заточено под ноутбук **INFINIX Inbook Y3 Max** (Ryzen 7 5825U, 16 ГБ LPDDR4X,
интегрированная AMD Radeon Vega): у тебя нет NVIDIA, поэтому всё ставится через
**Vulkan** — единственный надёжный способ использовать интегрированную графику AMD.

Движок — **stable-diffusion.cpp** (порт Stable Diffusion на C++, работает так же,
как llama.cpp): не нужен Python, PyTorch, CUDA или ROCm. Скачивается один архив ~29 МБ.
Интерфейс — **встроенный веб-интерфейс**, открывается в браузере.

## Быстрый старт

1. Положи `install.bat`, `start.bat`, `download_models.bat` в любую папку
   (лучше на диск C:, путь без русских букв и пробелов).
2. Запусти **`install.bat`** — он скачает движок и модель DreamShaper 8 (~2 ГБ).
   Останется только ждать. В конце он покажет список устройств — там должно быть
   слово `vulkan`.
3. Запусти **`start.bat`** — и всё. Он сам:
   - найдёт движок и **все** файлы моделей рядом с собой (а если не найдёт —
     поищет в Загрузках, на Рабочем столе и в Документах);
   - соберёт их в одну правильную папку `KolinAI\models\checkpoints`
     (именно там сервер ищет модели);
   - остановит старый сервер, если тот висел в памяти;
   - запустится и откроет в браузере `http://127.0.0.1:7860`.

`start.bat` можно запускать из ЛЮБОЙ твоей папки с батниками — если на диске
несколько копий KolinAI, он соберёт всё в одну рабочую копию рядом с собой.
Лишние копии папок потом можно просто удалить.

## В веб-интерфейсе

1. Нажми кнопку выбора модели (под полем промпта).
2. **Рецепт** смени с «FLUX.2 Klein Base 9B» на **«SD 1.x»** (FLUX.2 — модель
   на ~20 ГБ, для этого ноутбука не подходит).
3. В списке чекпойнтов выбери `DreamShaper_8_pruned.safetensors`.
4. **VAE** оставь пустым — у DreamShaper VAE уже встроена.
5. Нажми **«Модели загрузки»** и подожди 20–60 секунд.
6. Пиши промпт (на английском!) и жми **Generate** (Ctrl+Enter).

Если списка моделей нет — нажми «Файлы обновления и рецепты», закрой и снова
открой окно модели, либо перезапусти start.bat.

## Настройки генерации под этот ноутбук

Открой по очереди три панели настроек (чипы под полем промпта):

- **Разрешение**: выбери **«0,25 МП · 512»** (512×512). Это родное разрешение
  SD 1.5. Рецепт «SD 1.x» сам выставит 512×512, если включён чекбокс «Применить
  стандартные рецепты». 1024×1024 на SD 1.5 даёт кашу и генерируется в 4–6 раз
  дольше — не ставь.
- **Сэмплер** (панель «Образец и рекомендации»): Метод — **«Эйлер А»**
  (Euler A), Шаги — **20–25**, Планировщик — «По умолчанию». **Шкала CFG —
  замени 4 на 7** (диапазон 6–8; CFG 4 оставлен от FLUX и на SD 1.5 даст
  блеклые картинки).
- **Отрицательный запрос** (сворачиваемая строка над чипами) — вставь
  стандартный негатив:
  `lowres, bad anatomy, bad hands, text, error, missing fingers, extra digit, fewer digits, cropped, worst quality, low quality, blurry`
- **Результаты**: Количество изображений 1, Семена −1 (случайность) — норм.

Первая генерация 512×512 — примерно 1–3 минуты, плюс минута на разогрев.
Проверить, что считает именно видеокарта, можно в Диспетчере задач → вкладка
«Производительность» → GPU.

## Модели получше: SDXL (Juggernaut XL, Pony) — медленно, но качественнее

SDXL-модели дают заметно лучший результат, но они в 3 раза больше (≈7 ГБ) и
на твоей интегрированной графике **одна картинка занимает 5–25 минут**. Ставь
их, когда готов подождать; для быстрых набросков оставайся на SD 1.5.

После скачивания через `download_models.bat`:

1. В окне модели выбери рецепт **«SDXL»** (не «SD 1.x»!) и скачанный файл.
2. **VAE**: у Juggernaut — «Нет»; у Pony можно выбрать `sdxl_vae.safetensors`,
   если картинка выходит серо-жёлтой.
3. Дефолты рецепта (при включённом «Применить стандартные рецепты») правильные:
   **1024×1024, Эйлер, CFG 5, 20 шагов**. Для скорости можно снизить разрешение
   до 768×768 — это почти вдвое быстрее, качество всё равно выше SD 1.5.
4. Первая загрузка модели занимает 1–3 минуты — «Load models» подвиснет, это норм.

Особенности Pony: промпт начинается с тегов качества —
`score_9, score_8_up, score_7_up,` — а дальше простые теги через запятую.

Если при загрузке SDXL не хватает памяти или сервер падает — добавь в
`start.bat` в строку запуска сервера флаг `--type q8_0` (сожмёт модель при
загрузке примерно вдвое, почти без потери качества) и перезапусти.

## Сколько ждать (реалистичные ожидания)

- 512×512, 20 шагов, SD 1.5 — **примерно 1–3 минуты** на картинку.
- 768×768 — в 2–3 раза дольше. Для первого знакомства генерируй 512×512.
- Закрой Chrome/игры перед генерацией — память общая с процессором.

## Если что-то пошло не так

- **«В списке устройств нет `vulkan`»** (проверка в конце install.bat) → обнови
  видеодрайвер AMD (Adrenalin) с сайта amd.com и запусти install.bat снова.
- **«Движок не найден» при запуске start.bat** → значит install.bat ещё не
  запускался: запусти install.bat из той же папки.
- **«Моделей не найдено»** → модель лежит где-то совсем в другом месте. Запусти
  start.bat — он поищет в Загрузках, на Рабочем столе и в Документах; если не
  найдёт и там — положи файл модели в `KolinAI\models\checkpoints` вручную.
- **Список моделей в интерфейсе пуст** → нажми «Файлы обновления и рецепты»,
  закрой и снова открой окно модели. Не помогло — перезапусти start.bat
  (закрой окно сервера и запусти заново).
- **Скачивание оборвалось** → просто запусти тот же батник ещё раз, докачка
  продолжится с того же места (частичный файл лежит рядом с расширением `.part`).
- **Зависла генерация / не хватает памяти** → добавь в конец строки запуска в
  `start.bat` флаг `--offload-to-cpu` (веса хранятся в ОЗУ), а если и этого мало —
  `--type q8_0` (модель сжимается вдвое при загрузке) и/или `--vae-tiling`.
- **Рецепт просит FLUX.2 / Qwen и показывает «Выберите хотя бы один: VAE или
  TAE»** → это рецепт для другой, огромной модели. Переключи **Рецепт** на
  **«SD 1.x»** — он подходит для DreamShaper, Realistic Vision и AbyssOrangeMix.
- **SmartScreen предупреждение при запуске** → «Подробнее» → «Выполнить в любом
  случае» (батники самописные, без подписи).
- **Порт 7860 занят** → поменяй число `--listen-port 7860` в `start.bat` на любое
  другое, например 7861.

## Структура папок (справочно)

Сервер видит модели только в подпапках папки `models`:

```
KolinAI\
├── bin\           ← движок (sd-server.exe)
└── models\
    ├── checkpoints\   ← основные модели (DreamShaper и т.п.)
    ├── vae\           ← отдельные VAE
    ├── loras\         ← LoRA
    ├── text_encoders\ ← текстовые энкодеры (для SD 1.5 не нужны)
    └── controlnet\    ← ControlNet
```

start.bat сам создаёт эту структуру и сам раскладывает файлы по местам,
где бы они ни лежали. Вручную ничего переносить не нужно.

## Вариант для быстрой генерации: облачный GPU-сервер

Ноутбук — для черновиков. Для быстрой и качественной генерации можно взять
облачный GPU на несколько часов — картинка будет за секунды, а не минуты.

| Платформа | Что даёт | Карта нужна? | Цензура/ToS |
|---|---|---|---|
| **Cloud.ru** | **4000 бонусных ₽ новичкам** | рос. карта/СБП | своя VM, фильтров нет |
| **immers.cloud** | тестовый период до 30 дней | нет на тесте | своя VM, фильтров нет |
| **Lightning AI** | ~15 кредитов/мес ≈ 22 часа на T4 | нет, только телефон | своя машина (рег. бывает закрыта) |
| **Vast.ai / RunPod / Hyperbolic** | RTX 4090 по $0.20–0.39/час | депозит/крипта | голый контейнер, никаких фильтров |
| Colab / Kaggle | бесплатно | нет | **NSFW запрещён ToS — не рискуй аккаунтом** |

Готовый установщик — `server_setup.sh`: скопируй весь его текст и вставь в
терминал сервера (Ubuntu с NVIDIA GPU). Он сам поставит ComfyUI и скачает
**CyberRealistic Pony V18** (аналог PornWorks) + Juggernaut XL v9 Photo +
Realistic Vision 6. Потом открой в браузере порт 8188 (в панели платформы
открой порт в фаерволе: Cloud.ru — правила безопасности; Vast.ai — Open Ports).
В ComfyUI выбери модель в ноде «Load Checkpoint», промпт — в ноде
«CLIP Text Encode», жми Queue. Ориентир скорости: T4 — SDXL 1024 ~20–30 с;
RTX 4090 — SDXL ~5–8 с. Повторный запуск после перезагрузки сервера:
`bash ~/start_comfyui.sh`.

### Cloud.ru, шаг за шагом

1. cloud.ru → регистрация (нужна рос. карта/СБП для подтверждения, списаний
   нет — тратишь бонусы) → новичкам начисляется **4000 бонусных ₽**.
2. Создай сервер: регион Москва, **Ubuntu 22.04**, GPU **RTX 4090 / L4 / A100**
   (что доступно). Если GPU-квота новичку закрыта — запроси через поддержку
   (это нормально, отвечают быстро).
3. Подключись: кнопка «Консоль» в панели или SSH.
4. Вставь весь текст `server_setup.sh` → жди 15–25 минут.
5. В панели открой входящий порт **8188** (Безопасность/Фаервол → правило TCP 8188).
6. Браузер: `http://<публичный-IP-сервера>:8188` → ComfyUI → модель
   CyberRealisticPony_V18 → промпт по формату Pony выше → Queue.

**Важно про деньги:** когда закончил — **останавливай/удаляй сервер** (на
Cloud.ru и почасовых площадках счётчик капает, пока машина включена). Бонусы
сгорают по мере использования.

## Текстовый чат (LLM) — install_text.bat + start_chat.bat

- **install_text.bat** — ставит движок llama.cpp (CPU-сборка, ~24 МБ) и модель **Saiga Nemo 12B** (Q4_K_M, ~7.5 ГБ, Apache-2.0, заточена под русский язык, отказов минимум) в `KolinAI\text\`. Старую модель Qwen (если была) удаляет сама — освобождается ~4.7 ГБ.
- **start_chat.bat** — сам находит движок и модель (штатную Saiga или любой самый крупный `.gguf` в `models\`), проверяет, что движок реально запускается, снимает блокировку «файл из интернета», выбирает свободный порт (8080–8100) и открывает браузер только когда модель реально загрузилась. Если что-то не так — печатает конкретную причину: антивирус / недокачанная модель / не хватает ОЗУ. Если движка ещё нет — сам предложит запустить install_text.bat.
- install_text.bat при установке **проверяет движок сразу** (`llama-server --version`) — антивирус, убивший файлы, обнаружится при установке, а не при запуске чата.
- Скорость на этом ноутбуке ≈ 3–6 слов/сек (модель 12 млрд параметров, русское качество сильно лучше прежней 7B). Память диалога `-c 8192` — можно увеличить в start_chat.bat (например 16384), но чуть медленнее.
- Чат (~9 ГБ ОЗУ) и генерация SDXL (~10 ГБ) одновременно не влезают в 16 ГБ — открывай по очереди.
- Своя модель: просто положи любой `.gguf` в `KolinAI\text\models\` — батник подхватит его сам, если штатной Saiga нет (берёт самый крупный файл).

## Генерация по промту из txt — prompt_run.bat

Кладёшь рядом с батником txt с промтами (один для Juggernaut, другой для DreamShaper — как удобно), запускаешь **prompt_run.bat** и дальше руками ничего настраивать не надо:

1. Батник сам находит движок и модели (рядом, в `Загрузки\GGG-ai` целиком, на Рабочем столе, в Документах).
2. Ищет txt с промтами **рядом с собой** и в **`Загрузки\GGG-ai\KolinAI\SidAI\models`** (если там пусто — по всей папке GGG-ai). Пишешь **имя файла** (например `JUGGERNAUT XL v9`, можно без `.txt`) или номер из списка.
3. Говорит, сколько в файле промтов, показывает первые 10; полный список не льёт в окно. Посмотреть любой диапазон: `S 40-60` и Enter.
4. Пишешь **номер промта** — дальше всё сам: позитив из строки, негатив — свой из строки (после `|`) или блок `Negative prompt:`, а если его нет — стандартный для профиля.
5. **Сам выставляет настройки под модель:** Juggernaut XL → 1024×1024, 25 шагов, CFG 5, dpm++2m karras, clip skip auto; DreamShaper 8 (SD 1.5) → 512×512, 28 шагов, CFG 7, euler_a karras, clip skip 2. Модель определяется по имени (можно и вручную, Enter — сам). Если у промта в файле есть строка `SETTINGS: 28 steps | CFG 6.0 | 512X768` — шаги, CFG и размер берутся из неё для этого промта.
6. Запускает генерацию: результат в `outputs\` рядом с батником, картинка открывается сама. Сид случайный — виден в логе (запиши, чтобы повторить).

**Тихий режим.** На вопрос «Тихий режим?» ответь `1` (или просто Enter — обычная скорость): на время генерации батник переключит Windows в копию плана «Энергосбережение» с лимитом процессора 50%, убавит потоки движка до 2 и временно отключит сон. Вентиляторы шумят заметно меньше, картинка считается дольше (примерно вдвое). По выходу всё возвращается как было — план восстановится сам. Крышку во время генерации не закрывай в любом случае: от закрытия крышки ноутбук засыпает независимо от таймеров.

**Формат txt:** 1 промт = 1 строка (`промт | свой негатив`), или блоки из экспортёров: `Prompt: ...` / `Negative prompt: ...` — парсер понимает оба. Пустые строки и строки с `#` пропускаются. Примеры: `prompts_juggernaut.txt` и `prompts_dreamshaper.txt`.

## Галерея по всем промтам — prompt_all.bat

Тот же выбор txt-файла с промтами, но вместо одного промта батник сам прогоняет **все** и складывает в отдельную папку-галерею:

1. Сам находит движок, модель и профиль настроек — всё как в prompt_run.bat. Тихий режим спрашивает там же.
2. Показывает список txt, число промтов и первые 10; посмотреть любой кусок: `S 40-60` и Enter.
3. Пишешь, сколько генерить: **Enter — все** (например 50), или диапазон `1-20`. Сразу показывает ориентир по времени.
4. Картинки складывает в отдельную папку `outputs\gallery_<имя-txt>\`: `001.png`, `002.png`, … — номер файла = номер промта в txt.
5. Ошибка на одном промте прогон не останавливает: пишется в `_ошибки.txt` в той же папке, батник идёт к следующему.
6. **Докачивается:** если остановить (Ctrl+C) и запустить снова с тем же файлом — уже готовые номера пропустит и сделает только недостающие.
7. В конце сам собирает `gallery.html` — страницу с превью всех картинок (клик по превью — полноразмерная) — и открывает её в браузере.

**Про время и сон:** одна картинка 512×768 ≈ 10 минут на этом ноутбуке → все 50 промтов ≈ 8 часов обычного режима. Спящий режим на это время надо отключить: Параметры → Система → Питание → «Спящий режим» = Никогда (при питании от сети), или одной командой в cmd: `powercfg /change standby-timeout-ac 0`. В тихом режиме ещё дольше (~вдвое), зато почти без шума.

## ASMR Studio — asmr_studio.html

Профессиональная очистка и обработка звука в браузере: двойной клик, офлайн, аудио никуда не уходит. Открой WAV/MP3/FLAC (или запиши с микрофона), выдели мышкой участок чистого шума — студия построит по нему профиль и вычтет шум из всего трека.

**Очистка:** спектральный шумодав STFT с профилем шума (в т.ч. по выделению), де-щелчки, де-эссер, гейт, анти-фон 50/60 Гц с гармониками, HPF низов.
**🤖 AI-подбор обработки** — кнопка «AI-подбор»: студия сама анализирует трек (спектральный пол шумов, решётка гармоник 50/60 Гц с обязательной фундаменталой, щелчки по скачкам, шипящие 5–9 кГц, гул низа, динамика, корреляция стерео, тембр) и выставляет все ползунки под твой файл — с отчётом «что услышано и что выбрано». Тихий участок для профиля шума находит автоматически.
**Форма звука:** 5-полосный EQ, компрессор, бинауральное M/S-расширение с mono-bass, «уш-уш» автопанорама с задержкой на ухо (ITD), реверб (Freeverb, 4 гребёнки + аллпассы, pre-delay), LUFS-нормализация EBU R128 до цели, лимитер, фейды.
**Удобства:** waveform + спектр на canvas, A/B-плеер (до/после), 5 пресетов, пробел = play/pause, экспорт WAV 16/24/32-bit float.

Ядро DSP прогнано автотестами в Node: нотч −98 дБ @ 50 Гц, LUFS 0 дБFS стерео = −3.27 (эталон −3.01), лимитер держит потолок, M/S-тождество, реверб стабилен, тон после шумодава −0.16 дБ, LUFS полной цепи точно на цели.

## ИИ-агенты для кода — start_coder.bat, start_opencode.bat и start_gemini.bat

Все ставят Node.js в `KolinAI\tools\node` (zip-версия, без прав администратора, системный Node не трогается) и сами устанавливают агента. Желательно поставить Git (git-scm.com) — агентам он нужен для полноценной работы.

- **start_coder.bat** — OpenCode **с локальной нейронкой**: Qwen2.5-Coder 7B (4.7 ГБ, качается один раз в `%LOCALAPPDATA%\KolinAI\coder`) на процессоре через llama.cpp. **Без цензуры, без лимитов, без интернета и без карты — совсем.** Батник сам ставит всё нужное, сам пишет конфиг OpenCode (модель `KolinAI Local` выбирается сама), запускает сервер и OpenCode. Честно: скорость примерно 2–5 слов в секунду — агент думает медленно, но его можно нагружать хоть весь день. Картинки/чат во время работы кодера не запускать — по памяти не сойдутся (нужно ~7 ГБ). Движок общий с чатом (llama.cpp b12377) — отдельно не качается, если чат уже установлен.
- **start_opencode.bat** — просто запускает OpenCode (бесплатный open-source агент в терминале). Провайдеры подключаются внутри программы: `/connect` (Copilot, OpenRouter, Anthropic…), `/models` — выбор модели. Работает в папке, где лежит батник — скопируй его в свой проект и запусти оттуда.
- **start_gemini.bat** — Gemini CLI от Google: тот самый «безумный» бесплатный тариф — **~60 запросов/мин, ~1000 запросов/день** с обычным личным Google-аккаунтом, модели Gemini 3, контекст **1M токенов**, карта не нужна. Первый запуск: выбрать «Login with Google». Альтернатива — ключ GEMINI_API_KEY из aistudio.google.com (переменная окружения).
- Нюанс: Google может блокировать сервис по региону — из РФ/РБ может не пустить. start_coder.bat (локальная модель) работает всегда и без интернета.
- Ещё бесплатные агенты (проверено ноябрь 2026, лимиты плавают): бесплатные модели **OpenCode Zen** — прямо внутри OpenCode: `/models`, бесплатные помечены `free` (ротация: GLM, Kimi, Qwen3.8-Flash, иногда Grok Code Fast); **Rovo Dev CLI** от Atlassian — ~5 млн токенов/день бесплатно на Claude; **iFlow CLI** — безлимитные Kimi K2 / Qwen3 Max (`npm install -g @iflow-ai/iflow-cli`); **Google Jules** — 15 задач/день с PR на GitHub. Смертники: free-тир Qwen Code закрыт (апрель 2026), Ollama Cloud free убран (ноябрь 2026), Trae free = 10 премиум-запросов/мес (маркетинг врёт).
- Почему не «бесплатные» облачные альтернативы: бесплатный тир Qwen Code (2000 запросов/день) Alibaba отключил в апреле 2026; у Cerebras 1М токенов/день бесплатно, но на free-тарифе контекст урезан до 8К — агенту мало; у OpenRouter :free — 50 запросов/день. Щедрый безлимит без цензуры сейчас существует только локально.

## PowerShell 7 — install_powershell.bat

Ставит последнюю **PowerShell 7.7** в `%LOCALAPPDATA%\PowerShell7` **без прав администратора**: скачает архив с GitHub (~110 МБ), распакует, пропишет в PATH пользователя, предложит запустить. Системный Windows PowerShell 5.1 остаётся нетронутым. Весь набор KolinAI работает и без него — 5.1 встроен в Windows, но pwsh современнее (терминал, `$PSVersionTable`, новые операторы). Повторный запуск батника обновляет версию или сразу предлагает запустить уже установленную.
